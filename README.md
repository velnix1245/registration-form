# Форма реєстрації користувача

Навчальний вебпроєкт для лабораторної роботи №2 «Pull Request + Баг Репорт».

## Запуск

1. Завантажте файли проєкту.
2. Відкрийте `index.html` у браузері.
3. Заповніть форму та натисніть «Зареєструватися».

Сторонні бібліотеки, сервер та база даних не потрібні. Це локальний навчальний інтерфейс без сервера: дані не надсилаються і не зберігаються. Використовуйте лише вигадані тестові дані.

## Відомий недолік початкової версії

Підтвердження пароля не порівнюється з паролем. Це навчальний дефект для відпрацювання баг-репорту та Pull Request.
